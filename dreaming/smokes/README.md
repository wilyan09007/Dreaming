# smokes

End-to-end checks against the deployed services, run once after the human sign-ins (Supabase project and pooler URL, `modal token new` and `just deploy-trainer`, `fly deploy`, the ASI:One key) with the keys in `.env`; `just smoke` loads `.env` and chains `smoke_supabase.py`, `smoke_modal.py` and `smoke_api.py` (run `uv run --env-file .env python smokes/smoke_asi.py` on its own). Every script prints one `ok` or `FAIL` line per check and exits non-zero if any failed. `smoke_supabase.py` (`DATABASE_URL`) prints the IPv4 session-pooler host it used, checks the seven tables, inserts one `component="web" kind="batch.started" message="smoke"` event and reads it back as `contracts.Event` before deleting it, checks that the `supabase_realtime` publication holds `events`, `policies`, `runs` and `certificates` (and not `trace_rows`), and that `anon` can `SELECT` on `policies`, has no privilege on `trace_rows` or `weights`, and is read-only everywhere. `smoke_modal.py` (`MODAL_TOKEN_ID`, `MODAL_TOKEN_SECRET`) calls the deployed `dreaming-trainer` `embed` twice on `["hello"]`, asserts a 384-float vector, asserts the two answers are byte-equal (the determinism check), and prints cold and warm timings. `smoke_api.py` (`DREAMING_API`, default `http://127.0.0.1:8080`) checks `GET /healthz` is ok, that `GET /state` parses as `dreaming_api.main.State`, a `POST /budget` 0.05 round trip (the previous budget is restored), and that `GET /events?limit=5` parses as `Event`s. `smoke_asi.py` (`ASI1KEY`) posts one short message to `https://api.asi1.ai/v1/chat/completions` on `asi1-mini`, asserts a 200 with non-empty content and prints latency and usage; the body carries only `model`, `messages` and `max_tokens` because ASI:One rejects unknown top-level fields. Lint with `uv run ruff check smokes` and `uv run pyright smokes`.
