# Correctness prediction: is a separate "will it be right?" model redundant with the logits?

Date 2026-10-17. Method: WebSearch only. **WebFetch failed in this container (DNS: arxiv.org and alphaxiv.org not resolvable), so no paper body was read; every external number below comes from WebSearch result summaries of the paper's abstract, HTML or PDF snippet and is marked "(snippet)".** Treat all 2026 items as single, un-replicated preprints unless a venue is given. Local evidence: `smokes/s15_confidence_signals/RESULTS.md` (S15), `smokes/FINDINGS.md` (S3, round 2), `smokes/research/confidence-and-hypernets.md` (Part A, not repeated here), `smokes/research/certification-deferral.md`. This note extends Part A; it does not redo it.

## Bottom line

1. **The user is right for the student side, and the 2025-26 literature does not change that.** Use the student's own top-2 gap (or max-prob, they tie) as the gate and certify it with the grid Clopper-Pearson. Do not train a second model on the prompt (S15: 0.56-0.76 vs 0.88-0.90). Keep "no label smoothing" as a recipe guard only (Xia et al., ICLR 2025, https://arxiv.org/pdf/2403.14715, snippet; post-hoc logit normalisation fixes it if ever smoothed): a grep of `smokes/**/*.py` finds no student that uses it, so it is not worth a smoke slot. The training-side arm to spend that slot on is a Gatekeeper-style confidence-tuning loss (Rabanser et al., NeurIPS 2025, https://arxiv.org/abs/2502.19335, search summary).
2. **Run S21 as already specified, and add arms; do not redesign it.** S21 (`smokes/s21_hidden_state_probe/{prep,extract,analyze}.py`) is already a router-side smoke: it probes Qwen2.5-0.5B-Instruct acting as the cheap model, target "cheap == E1". Add two arms: probe + student==cheap agreement (f1), and a probe on the bge student; report certified coverage at 10/15/20% next to AUROC. My earlier idea (probe on the student's hidden state predicting cheap == expensive) is a different smoke and is labelled a new design, not S21. "Expect little gain" for label outputs is a prior to test, not a finding: in the single-token YES/NO setting of https://arxiv.org/abs/2609.04582 (search summary, preprint) the margin reaches AUC 0.887 but linear probes reach about 0.96. Directly relevant and already in Part A: an open model's prefill activations predicting a closed model's correctness close 45.58% of the gap to the oracle at 74.31% cost saving (https://arxiv.org/abs/2603.20895, self-reported).
3. **Router side: the best signal is disagreement between independent predictors, not a better single-model score.** S15's "free student label == cheap label" (AUROC 0.90-0.96) matches the black-box literature: cross-model disagreement beats within-model entropy (0.73 vs 0.59 MMLU in v2, https://arxiv.org/html/2603.25450v2, search summary; Hamidieh's long-form "0.72 vs 0.64" is unconfirmed and total uncertainty does not beat aleatoric in every cell, https://arxiv.org/pdf/2604.17112). Keep it as the default; use the cheap model's logprob gap only as tie-break and only where it exists (S15 f3, 0.944-0.955). AUROC is not what limits certification, though: with 100 calibration rows nothing certified at 2-5% and 5-10% budgets need roughly 500-1,000 rows (`smokes/FINDINGS.md` l.71). The next router smoke is a calibration-size sweep (100/300/1,000 E1 rows) on f3, not a new signal.
4. **For black-box cheap models with no logprobs: the fallback is student==cheap agreement (S15 f1, AUROC 0.897 / 0.916 / 0.921), which costs nothing and needs no extra call.** This contradicts my earlier recommendation of K=2-5 sample agreement, which S15 measured and which loses: cheap-model self-consistency scored 0.684 / 0.546 / 0.499 with two draws and 0.712 / 0.566 / 0.516 with three, below even the free student gap (0.665 / 0.651 / 0.683); verbalized confidence on gpt-5.4-nano scored 0.782 (`smokes/s15_confidence_signals/RESULTS.md` l.91-97). Self-consistency stays only as an extra arm to measure against f1 on the same rows. Externally, the "0.52-0.57" I quoted was wrong: https://arxiv.org/abs/2604.12491 reports 0.523 for Llama-3.3-70B verbalized confidence and 0.42-0.76 across models (search summary). Agreement is not truth: 48% of answers with agreement >= 0.8 were wrong for the most self-consistent model in the main audit, an OpenAI-family model; the Claude tiers were only an exploratory K=10 check without temperature control (https://arxiv.org/abs/2607.08065, search summary, single-author preprint). Wrong consensus bites on mission 5 only when the expensive tier is itself wrong; test a rescue target ("E1 right and cheap wrong", Signed Rescue Routing, https://arxiv.org/abs/2609.07786, single preprint) next to "cheap == E1" on S15 rows with known gold.
5. **Human-review deferral (mission 4) is the one setting where a separate learned head is justified, because the target is not in the teacher's logits.** Keep S3's design (head over student scores + tool flags + history, trained on reviewer corrections, certificate against corrections). Literature basis: confidence deferral is suboptimal under label noise, specialist downstream models and train/test shift (Jitkrittum et al., NeurIPS 2023, https://arxiv.org/pdf/2307.02764, snippet). Next smoke: test the head with features the logits cannot contain (tool flags, reviewer identity, time-since-last-correction) and report gain over the gap on a split where the reviewer's style changes mid-stream.
6. **Cheap to add to the certificate pipeline, no new model:** rank by the likelihood-ratio style score only if covariate shift appears (Heng & Soh, ICLR 2026, https://arxiv.org/abs/2505.15008, snippet; code reported at github.com/clear-nus/sc-likelihood-ratios, not checked). Otherwise stay with the raw gap.
7. **Logprob availability rests on primary measurements, not forum posts.** S15 got usable returned-label logprobs from gpt-5.4-nano with reasoning off (`logprobs=True, top_logprobs=5`), its best single-model signal (b1 0.894), and found no qwen3-32b provider returning label logprobs (`probe_q32.py`). Anthropic's official Messages reference shows no logprobs request parameter in the portion read (https://platform.claude.com/docs/en/api/messages, partial fetch). Design stance: assume no logprobs for Claude and for reasoning models, and make the router work without them. Forum posts below are secondary.

No 2025-26 paper found compares a hidden-state probe to the max-softmax of a fine-tuned small classifier on Banking77-style intents.

### 3. When is a separate predictor not redundant? (theory and conditions)

| Source | URL | Date | Condition | Numbers |
|---|---|---|---|---|
| Jitkrittum et al., When Does Confidence-Based Cascade Deferral Suffice? | https://arxiv.org/pdf/2307.02764 | 2023 (NeurIPS) | Optimal deferral rule characterised; post-hoc deferral beats confidence when (i) downstream models are specialists, (ii) labels are noisy, (iii) train/test shift | Abstract-level; gains not retrieved (snippet) |
| Heng & Soh, Know When to Abstain | https://arxiv.org/abs/2505.15008 | 2025/2026 (ICLR) | Neyman-Pearson: the optimal selection score is a likelihood ratio of correct vs wrong; new post-hoc scores for covariate shift outperform baselines (code exists, MIT, github.com/clear-nus/sc-likelihood-ratios, but its README example is ImageNet only; "language" is unverified) | Numbers not retrieved (snippet) |
| Kamath, Jia, Liang | https://arxiv.org/abs/2006.09462 | 2020 | Under domain shift a trained calibrator beats MaxProb | 56.1% vs 48.2% coverage at 80% accuracy (from Part A) |
| Dreaming S3 (local) | smokes/FINDINGS.md | 2026-10 | Head trained on reviewer corrections, 1000 corrections | Weak student: review share for 80% catch 28.5% to 24.2%, AP 0.58 to 0.72 (self-reported, gold label stands in for reviewer) |

Synthesis (my reasoning): a second predictor is redundant when its target is a deterministic function of the model's own output distribution and the input stays in distribution. It stops being redundant when (1) the target depends on information the logits never saw (tool flags, history, reviewer identity, time), (2) the target label is produced by a process other than the model's training labels (human corrections, label noise), (3) the input distribution moves so that the logits are confidently wrong, and (4) there are no logits. Mission 4 hits (1) and (2) directly. Mission 1 (student) hits none of them at launch, which is what S15 measured.

## What this changes in the plan

- **Student gate:** unchanged (top-2 gap). Keep "no label smoothing" as a recipe guard. Replace the label-smoothing ablation in the next student run with a Gatekeeper-style confidence-tuning arm, judged on certified coverage, not only AUROC.
- **S21 (hidden-state probe):** run as specified (cheap-model probe, cheap == E1, stage 2 for calibration rows). Add arms: probe + f1, probe on the bge student. Report certified coverage at 10/15/20%.
- **Router default:** agreement(student, cheap) with logprob tie-break where logprobs exist (f3). For black-box cheap models without logprobs: f1 alone ($0, 0.90-0.92). Self-consistency is an extra arm measured against f1, not the fallback.
- **Next router smoke:** calibration-size sweep (100/300/1,000 E1 rows) on f3, because calibration rows, not signal choice, limit certification at 2-10% budgets. Also check whether Conformal Cascade (2607.25018) needs fewer rows than grid Clopper-Pearson on S15 data.
- **Wrong consensus:** evaluate a rescue target next to "cheap == E1" on S15 rows where gold is known.
- **Mission 4:** keep the learned head and make the case in the product text that this is the one place it is not redundant. Report incremental AUROC over the raw gap, split by whether the head sees features absent from the logits. State that the S3 head is a score-feature LR, and its evidence so far uses gold as the reviewer.
- **Certification:** agreement signals are discrete (0/1 plus a tie-break), which hurts the grid certifier because many rows tie; break ties with the gap or a probe score, and keep the grid.
- **Doc wording:** do not claim "a probe beats logits" or "a probe adds little" for typed steps; both are priors until S21 reports.

## Open questions

1. Does a hidden-state probe on a fine-tuned or frozen small student add anything over the gap for Banking77/CLINC-style labels? No source tested it; S21 is the test.
2. How large is the agreement-signal AUROC in DART and in the Gorbett/Hamidieh papers on classification-shaped tasks? Only abstract-level numbers were retrieved (WebFetch was down); read the PDFs when network allows.
3. What is the current logprob support per provider beyond what S15 measured (Gemini 3.x via Vertex vs AI Studio; Claude beyond the partial Messages reference read)?
4. Does a Gatekeeper-style loss improve certified coverage, not just AUROC, for a 33M encoder at 770-3,080 rows? (Focal loss: still no source found.)
5. Does the S3 head's advantage survive real reviewer corrections (non-gold)? S3 used gold as the reviewer; AlleNoise and ChaosNLI (see `certification-deferral.md`) are the nearest real sets.
6. Wrong-consensus risk: on tasks where the expensive tier is itself wrong, can agreement with a cheap model certify a wrong answer? Quantify with S5/S15 data split by whether E1 equals gold.

### Bottom line

1. **Most severe: bottom-line item 4 contradicts the repo's own S15 numbers, and the note does not say so.** It recommends K=2-5 sample agreement and "never verbalized". On S15's router, cheap-model self-consistency scored 0.68 / 0.55 / 0.50 AUROC (two-draw), and 0.71 / 0.57 / 0.52 with 3 draws. That is below the free student gap (0.65-0.68) and far below student==cheap agreement (0.90-0.92). Verbalized confidence on gpt-5.4-nano scored 0.78. The quoted external "0.52-0.57" is also wrong: 2604.12491 gives 0.523 for Llama-3.3-70B verbalized and 0.42-0.76 across models. Fix: for black-box cheap models, use student==cheap agreement, which needs no logprobs and no extra call. Add self-consistency only as a measured arm, never as the default.
2. **S21 is already a router-side smoke, and the note silently changes its design.** As written, S21 probes a local cheap LLM (Qwen2.5-0.5B-Instruct) for "cheap == E1". The note proposes a probe on the student predicting "cheap == expensive", which is a different smoke. Bottom-line item 2 also says "student side" in its header and "router side" in its body. Run S21 as specified and add one arm: probe + student==cheap agreement. Cite the directly relevant 2603.20895, already listed in Part A: open-encoder prefill probes predicting a closed model's correctness (45.58% of the oracle gap, 74.31% cost saving, compared only with "semantic" baselines).
3. **The router recommendation ranks signals by AUROC, but S15 says calibration rows are the binding constraint.** At 100 calibration rows nothing certified at 2-5%. 5-10% budgets need 500-1,000 rows. Make the next router smoke a calibration-size sweep on the best existing signal (f3), not a new signal.
4. **Several numbers are misquoted or overstated:**
   - Cross-Model Disagreement (2603.25450) gives an MMLU CMP AUROC of 0.73 (v2), not 0.75, and the "Gorbett & Jana" byline is unconfirmed.
   - Hamidieh's "0.72 vs 0.64" is unconfirmed. Total uncertainty does not beat aleatoric in every row.
   - Ding's frontier model is an OpenAI-family model. The Claude tiers were only an exploratory K=10 check with no temperature control, not a "repeat".
   - ProbeDrift says "poor robustness beyond near-OOD", not "near chance".
5. **Missed 2025-26 cascade work:**
   - Gatekeeper (NeurIPS 2025) tunes the small model's confidence for deferral. It is a training-side lever the note rules out by omission.
   - Signed Rescue Routing (2609.07786) predicts whether the large model rescues the small one, which is the right target when the expensive tier is itself wrong.
   - Conformal Cascade (2607.25018) puts a certificate on a multi-tier cascade.
   Add a Gatekeeper-style confidence-tuning arm to the next student run in place of the label-smoothing ablation. That ablation is moot: no Dreaming student uses label smoothing.

8. Missed 2025-26 work. The note's student-side "nothing to change in training except avoid label smoothing" is not the whole literature:
   - Gatekeeper (Rabanser et al., NeurIPS 2025, https://arxiv.org/abs/2502.19335, https://neurips.cc/virtual/2025/poster/116238): a loss that tunes the small model to be confident where it is right and defer otherwise, across encoder-only and decoder models. It is compared against a single untuned baseline (search summary).
   - Signed Rescue Routing (https://arxiv.org/abs/2609.07786): it targets whether the large model rescues the small one. Area under the accuracy-compute curve 0.6811 vs 0.6716 for a learned small-error predictor vs 0.6659 for entropy (MMLU/HellaSwag/ARC, Qwen3-4B/8B, single preprint, search summary). This addresses the note's wrong-consensus caveat directly.
   - Conformal Cascade (https://arxiv.org/abs/2607.25018): distribution-free accuracy guarantees for multi-tier cascades, with tier-1 acceptance from 0% (MMLU-Pro, GPQA-Diamond) to 95.6% (Belebele-Eng) (search summary). It is the closest published analogue to Dreaming's router certificate.
   - UCCI (https://arxiv.org/abs/2605.18796): token-margin uncertainty with isotonic calibration gives 31% cost reduction at micro-F1 0.91 (search summary, self-reported).
